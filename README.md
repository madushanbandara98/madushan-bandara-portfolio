The website is designed to help recruiters, hiring managers, and potential collaborators quickly understand how I combine management knowledge with practical technical execution.

## Run locally

Requirements: Node.js 18.18 or newer and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). If that port is occupied, Next.js will display the available local port in the terminal.

## Production build

```bash
npm run build
npm start
```
